# 部署指南

把 T10M 对话模型装进《我的世界》基岩版有三种方式，从易到难：

| 方式 | 需要什么 | 适合 |
|---|---|---|
| A. 导入做好的世界 | 只要游戏 | 想直接玩 |
| B. 行为包安装 | 只要游戏（国际版或网易版） | 想装进新世界，或部署自己训练的模型 |
| C. 调试桥搭建 | 网易 MC Studio + mod-debug-bridge + Python | 开发和实机验收 |

## 电脑要求

- **内存**：游戏进程约 7–9 GB，**建议 32 GB**。16 GB 能跑起来，但要关掉其他大程序。
- **CPU**：单核性能决定速度。i5-13400F 每个字约 11 秒；生成期间游戏会一直卡住，属于正常现象。
- 游戏版本：在网易版约 v1.21.120 上实测。国际版理论上可用（只用了原版命令），但没有实测。

## 键盘怎么用

键盘在世界里，是一面墙：每个键是按钮、石头、命令方块的组合，上面有告示牌标字。

| 键 | 作用 |
|---|---|
| 字母键 | 输入拼音；屏幕下方的提示栏显示候选字 |
| 1–9 | 选候选字 |
| 上页 / 下页 | 候选字翻页 |
| 退格 / 清空 | 删拼音或删字；清空会开始一段新对话 |
| **发送** | 把你这句话发给模型，它会一个字一个字地回答（每个字约 11 秒） |
| 自检 | 跑一个固定的例子，比对几百个整数，聊天栏显示 PASS 或 FAIL |
| 初始化 | 建立全部记分项和常数；第一次使用、或者出了问题时按 |
| 开机 / 关机 | 加入 / 移除远处模型所在的常加载区 |

注意：
- **一个键一个键地按，看到屏幕下方的提示栏变了再按下一个**（一般 3–5 秒）。310 万个命令方块的世界，空闲时一个 tick 也要约 0.8 秒，每个键要两三个 tick 才处理完；按太快，后一个键会覆盖前一个。
- 一段对话（你的字加上它的字）最多 64 个字，满了按"清空"。
- **存档退出前一定要按"关机"**。如果常加载区开着就存档，下次进世界会在加载界面卡十几分钟。
- 模型放在 x = 32768 一带的远处。不要飞过去看：渲染几百万个命令方块会让游戏非常卡。

## A. 导入做好的世界

1. 从 Releases 下载 `MCBE_Transformer_T10M.mcworld`，双击导入。网易版用 MC Studio 导入存档。
2. 进入世界。你在出生点，面前就是键盘。
3. 按 **开机**。远处 310 万个命令方块开始加载，第一次要几分钟，期间游戏卡住。
4. 按 **初始化**，聊天栏出现"初始化完成"。
5. 想确认模型完好，可以按 **自检**：它会生成一段固定回答，约几分钟，最后应显示 PASS。
6. 开始聊天：打拼音 → 选字 → 发送。

## B. 行为包安装

适用于发布的 `d10f`，或者你用 `python -m t44k.pipeline build` 生成的任何模型。

1. 新建世界：**超平坦**、开启作弊。最好用创造模式，方便飞。
2. 挂上行为包：
   - 国际版：双击 `d10f.mcpack` 导入，在世界设置的"行为包"里启用。
   - 网易版：在 MC Studio 里导入 `d10f_netease.zip` 组件，挂到测试地图上。
3. 进世界，在聊天栏输入：
   ```
   /function mct/install
   ```
   它会：
   - 设置 `gamerule maxcommandchainlength 4000000` 和 `commandblockoutput false`；
   - 在 x=32768 一带加常加载区 `stga`；
   - 由行为包的 tick 函数等区块加载好，**每个 tick 加载一块结构**，共 15 块。每块约 26 万个命令方块，加载时游戏会卡几秒到几十秒。聊天栏会显示"已加载 k/15"。
   - 每块加载完后，安装器会用 `structure delete` 删掉游戏对这块结构的内存缓存。不删的话，游戏进程会涨到 18 GB；删了之后实测装完约 7 GB，运行时约 8.7 GB。
4. 看到"模型已装好"后，飞到想放键盘的空地，**面朝南**，输入：
   ```
   /function mct/keyboard
   ```
   键盘会出现在你前方约 3 格处，是一面约 15 格宽、10 格高的墙。
5. 按 **初始化**，然后就可以聊天了。
6. 可选：退出世界，移除行为包，再进来。世界里只剩原版方块，照常能用（按"开机"、"初始化"）。

安装没有动静时，检查：
- 是否开了作弊；
- 行为包是否启用；
- 世界是否超平坦：安装器通过读取 y = −64 的基岩来判断区块是否已加载。

## C. 调试桥搭建（开发者）

这是项目开发时用的方式，可以逐 token 比对游戏和 Python 的整数。

1. 安装 [mod-debug-bridge](https://github.com/sevenstars0/mod-debug-bridge)。这是网易 ModSDK 调试工具，只在开发期使用。
2. 导出：
   ```
   python -m t44k.pipeline build models/d10f out/d10f
   ```
   导出目录必须是纯 ASCII 路径，因为游戏内的 Python 2 要读它。
3. 在游戏里通过调试桥执行 `t44k/ingame_staged.py`（把 `DIR` 设为 `out/d10f/export/`）：
   1. `setup()`；
   2. `gamerule maxcommandchainlength 4000000`；
   3. 建 `t4`、`t4c` 记分项；
   4. `probe_names()`，应返回空列表；
   5. 反复调用 `place_all(400000)`，直到返回 `done`（310 万块约 2 分钟）；
   6. `init()`；
   7. `start_auto()`，跑 4 个测试对话，结果在 `AQ['res']`，每项 `ok` 都应为 True。
4. 键盘：执行 `t44k/m7_ingame.py`（`M7` 设为 `out/d10f/m7/m7.json`），依次运行 `probe_texts()`、`place_far()`、`place_wall_at_player()`。

## 性能参考（实测）

| 模型 | 命令方块 | 每字 | 游戏内存 |
|---|---|---|---|
| T1M（125 万参数） | 85 万 | 约 2.9 s | 4–5 GB |
| T4M（447 万） | 180 万 | 约 5.3 s | 6.8 GB |
| T10M（966 万） | 310 万 | 约 11 s | 9.3 GB |
