# 训练工坊使用说明

训练工坊是一个窗口程序。你选好语料和模型大小，点"开始"，它会依次完成：准备语料 → 训练 → 打包模型 → 生成能装进《我的世界》的存档和行为包。中途可以随时暂停，下次接着来。

## 第一次使用

1. 安装 Python 3.10 或更新版本（python.org），安装时勾选 **Add to PATH**。
2. 双击 `安装环境.bat`。它会在项目文件夹里建一个独立的运行环境，并装好 PyTorch（约 3 GB，要联网，十几分钟）。
3. 双击 `启动工坊.bat`，打开窗口。

## 五个页面

### ① 电脑

打开时会自动检查显卡、显存、内存和硬盘，并告诉你这台电脑在游戏里最多能跑多大的模型。

- 训练需要 NVIDIA 显卡。没有显卡也能用，但训练会慢几十倍。
- 显示"加速编译不可用"时也能训练，只是慢一倍左右。
- 依赖没装全，可以点"安装 / 修复依赖"。

### ② 语料

四种来源可以任意组合。"比例"是每一批训练数据里各占多少，程序会自动换算成合计 100%。

| 来源 | 适合 | 怎么准备 |
|---|---|---|
| DeepSeek 老师语料 | 书面语、通顺的短句 | 填 DeepSeek 密钥和句数，点"开始生成"。约 0.5 美元 / 10 万句（以 DeepSeek 当前价格为准），可以随时关掉，下次接着生成。密钥不会保存。需要先准备好中文维基，用来取话题词 |
| 中文维基百科 | 百科式的句子 | 点"打开下载页"，下载 `wikipedia-cn-20230720-filtered.json`，放到 `data\wiki_raw.json`，或者在窗口里选文件 |
| LCCC 对话 | 让模型会聊天 | 下载 `lccc_base_train.jsonl.gz`、`lccc_base_valid.jsonl.gz`、`lccc_base_test.jsonl.gz` 三个文件，放进一个文件夹。**只能用于研究和非商业用途**，要勾选确认 |
| 我自己的文本 | 特定主题、特定说话风格 | 添加 txt 文件（UTF-8 或 GBK 都行）。普通文章直接放；聊天记录要勾选"这些是对话"，格式见下 |

**对话文本的两种格式**：

```
你好|你好呀|在干嘛
吃饭了吗|还没呢|那快去吃吧
```

或者一行一句、空行隔开一段对话（"小明：""A:"这类说话人前缀会自动去掉）：

```
小明：今天好累啊
小红：早点休息吧

A:周末干嘛
B:在家睡觉
```

**字表**：模型只认识 1024 个字。
- 一般用"发布模型的字表"，日常中文覆盖约 94%。
- 如果你的文本是古文、专业领域这类常用字很不一样的内容，选"按我选的语料新建字表"。

**参考配方**：
- 和发布的 T10M 一样：老师语料 0.40 + 维基 0.15 + LCCC 0.45；
- 不花钱：LCCC 0.7 + 维基 0.3。实测（T4M）能聊，但比全配方差一截：200 句对话里万能回答占 43%（发布的 T10M 是 23.5%）；
- 专门的主题：你的文本 0.3–0.5，加上 LCCC 或维基保底。只用自己的文本、又不到几十万字的话，模型容易死记硬背。

### ③ 模型

| 尺寸 | 参数 | 游戏里每个字 | 游戏内存 | 默认训练时间（RTX 4070 SUPER） |
|---|---|---|---|---|
| 迷你 | 22 万 | 约 0.1 秒 | 约 1.5 GB | 约 1 分钟（只能说胡话，用来试流程） |
| T1M | 125 万 | 约 3 秒 | 约 4.5 GB | 约 35 分钟 |
| T4M | 447 万 | 约 5.3 秒 | 约 7 GB | 约 2 小时（实测 8 万步 2 小时 5 分） |
| T7M | 682 万 | 约 7.9 秒 | 约 8 GB | 约 3.5 小时 |
| T10M | 966 万 | 约 11 秒 | 约 9.3 GB | 约 7.5 小时 |

训练时间按显卡不同会有出入。游戏内存是游戏进程本身占用的部分，电脑总内存最好比它多 6 GB 以上。

- **项目名**：英文小写字母、数字和 `_`，会用在文件名上。
- **游戏里显示的名字**：可以写中文。
- **逐整数核对**：用严格的解释器把所有命令完整执行一遍，和标准答案逐个比对。小模型只要几分钟；T10M 第一次约 3 小时，之后有缓存就快了。想放心就勾上。

### ④ 训练与生成

- **开始 / 继续**：从上次停下的地方接着做。已经完成的步骤会自动跳过。
- **暂停训练**：会在下一个整百步存好进度再停，下次点"继续"接着练。
- 进度条显示训练步数、已用时间、预计剩余时间和当前的验证集准确率。
- 下面的日志框显示当前步骤的详细输出。出错时，最后会显示出错信息。
- 全部完成后点"打开输出文件夹"。

**训练时不要开着《我的世界》的大世界**，两个一起抢内存，电脑会很卡。

### ⑤ 试聊

模型训练好后，可以先在电脑上聊几句看看效果。这里用的是和游戏里完全相同的整数计算和解码规则：这里怎么回答，装进游戏后就怎么回答，只是快得多。也可以选发布的 T10M 对比一下。

## 输出文件怎么用

`projects\项目名\build\输出\` 里有：

| 文件 | 用法 |
|---|---|
| `项目名_网易版组件_自动安装.zip` | 网易版：在 MC Studio 导入组件，新建超平坦世界、开启作弊、挂上组件，进入世界。15 秒后自动安装（游戏会卡十几次），装好后键盘出现在你面前，并自动初始化 |
| `项目名.mcworld` | 国际版：双击导入，打开世界后同样会自动安装 |
| `项目名_国际版行为包_自动安装.mcpack` | 国际版：挂到新建的超平坦世界上，效果同上 |
| `..._手动安装` | 不想自动安装时用：新世界里输入 `/function mct/install`，装好后面朝南输入 `/function mct/keyboard`，再按"初始化" |
| `怎么用.txt` | 以上说明的简版 |

在游戏里：
- 字母键打拼音，数字键选字，按"发送"；
- 看到屏幕下方的提示变了再按下一个键；
- "自检"会逐整数核对；
- 存档退出前先按"关机"。

## 常见问题

- **训练出错 / 显存不够**：先换小一号的尺寸。批大小在项目文件 `projects\项目名\project.json` 里（`"batch": 256`），可以改成 128。
- **改了语料或尺寸**：保存时程序会提示，已有的训练进度会作废，要从头开始。
- **装进游戏后不说话**：按"自检"。显示 FAIL 的话，把 `projects\项目名\build` 里的日志发给开发者。
- **国际版存档**：自动安装的存档目前只在网易版上实测过（组件方式），国际版的实测还在进行中。
