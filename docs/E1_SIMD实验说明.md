# 实验一（E1）：实体选择器 SIMD vs 拓扑编译（v1.1.1）

**要回答的问题**：把三值矩阵写进实体标签，用 `scoreboard players operation @e[tag=p17] sa += x17 sb` 这类选择器命令批量算，会不会比现在"每个非零权重一条命令方块"快很多？结果决定 0.1B 路线走不走实体。

同一个 768×256 三值矩阵、同一个输入向量，两种算法：

| 算法 | 权重存在哪 | 每次矩阵乘的命令数（10% 非零） |
|---|---|---|
| 拓扑（现在的做法） | 命令文本 | 约 2 万条 `+=`/`-=` |
| 实体 SIMD | 768 个盔甲架身上的标签 `p<j>`/`n<j>` | 513 条选择器命令 |

每个测试结束后，游戏内会逐个比对 768 个输出整数，只有全部与 Python 结果一致才打印 PASS。

## v1.1.1 改了什么

- **修复低级错误**：v1.0.x–v1.1.0 的记分项叫 `sb`，被网易敏感词过滤器当成屏蔽词，含它的命令全被静默吞掉，所以按钮没反应、T0 永远不结束。现在改名为 `e1v`/`e1a`，构建时会检查所有命令里有没有这类词。

## v1.1.0 改了什么（根据 E0 的结果）

- v1.0.2 每 tick 8 万多条命令，结果所有命令都停止响应；E0 证明每 tick 4 万条以内正常。所以现在**每个测试每 tick 最多约 4 万条命令**：填充链改成 1 条 2 万条，去掉了拓扑 25%。
- SIMD 每 tick 只做 1 次矩阵乘（原来 4 次），避免每 tick 改动的分数过多。
- 全部命令链、实体池、干扰实体都放在 x=4096 的常加载区，远离渲染距离。**测试期间不要飞过去。**

## 计时原理

游戏里没有真实时钟，所以用秒表。每个测试都和一条固定的 2 万条命令"填充链"一起跑 N tick（E0 测得每 tick 约 125 ms，超过 50 ms）：

- 墙钟时间 ÷ N = 每 tick 耗时（每 tick 都超过 50 ms，不会被 20 TPS 上限遮住）
- 减去 T0（只有填充链）的耗时，就是被测内核本身的耗时

**这次请用 N=100**（默认值）。E0 用 N=20 时秒表误差占比太大。

## 测试顺序

每个测试：**按下按钮的同时开始计时；看到"完成 … 请停表"就停表**，然后记下秒数和 PASS/FAIL。

| 步 | 操作 | 记录 |
|---|---|---|
| 1 | T0 空载（跑两次，记第二次） | 秒。应该明显超过 5 秒（大约 12 秒） |
| 2 | T5、T10 | 秒 + PASS |
| 3 | 装载10%（等到"装载完成"），再跑 S10、V10、R10、P10 | 秒 + PASS |
| 4 | 按一次「+250干扰」，再跑 T0、S10、V10、R10、P10。帧率没明显下降的话，再按一次（共 500 个）重跑 | 干扰数量 + 秒 + PASS |
| 5 | 清干扰；装载5% → S5；装载25% → S25 | 秒 + PASS |
| 6 | **最后**：装载50% → S50 | 秒 + PASS |

- 每个测试进行中，可以在聊天栏敲一次 `/say ping`，确认命令还有响应。
- **一旦 `/say ping` 不响应，或某个测试超过 1 分钟没完成**：立刻停下，保存退出，把出事的那一项告诉我，不用再按「停止」（那时按钮也不会响应）。
- S50 每 tick 要改约 10 万个分数，最可能踩到未知的上限，所以放在最后。
- 装载 10% 如果就已经明显卡顿，先停下告诉我，我改成 256 个输出的小实体池。

## 各测试含义

| 测试 | 内容 |
|---|---|
| T0 | 只有填充链（基准） |
| T5 / T10 | 拓扑：每个非零权重一条命令方块 |
| S5 / S10 / S25 / S50 | SIMD：选择器只带标签 `@e[tag=p17]` |
| V10 | SIMD：选择器再加区域限制 `@e[x=…,dx=…,tag=p17]`，看能不能缩小扫描范围 |
| R10 | 把 768 个实体结果读回假玩家，用 `@e[tag=i7]` 定位 |
| P10 | 同上，用坐标 `@e[x,y,z,dx=0]` 定位 |
| +250干扰 | 在别处多放 250 个无关盔甲架（上限 1000），看选择器是不是在扫描全世界的实体 |

## 回传

```
T0: 秒    T5: 秒/PASS   T10: 秒/PASS
S10: 秒/PASS   V10: 秒/PASS   R10: 秒/PASS   P10: 秒/PASS
干扰（__ 个）后 T0:  S10:  V10:  R10:  P10:
S5:   S25:   S50:
（可选）SrvTime 大致数值、卡顿、报错
```

## 判据

R = SIMD 每秒有效权重更新数 ÷ 拓扑每秒有效权重更新数

- R < 1：放弃 SIMD，走结构分页 + 拓扑
- 2 < R < 5：值得在 FFN 上继续测
- R > 5：0.1B 路线改走实体 SIMD
- R > 10：重新评估 0.3B–1B
